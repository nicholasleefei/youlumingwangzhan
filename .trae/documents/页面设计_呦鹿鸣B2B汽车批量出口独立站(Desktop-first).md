# 页面设计说明（Desktop-first）

## 全局规范（适用于全站）
### Layout
- 以 1200px 内容容器为主（`max-width: 1200px; margin: 0 auto; padding: 0 24px;`），桌面优先。
- 主要布局：顶部导航 + 内容区分段（section）+ 页脚。
- 列表与卡片：CSS Grid（桌面 3-4 列；平板 2 列；移动 1 列）。

### Internationalization（i18n）
- Header 右侧必须包含语言选择器（下拉/弹层均可），支持切换并保持当前页面路径。
- 文案优先覆盖中英；其余语言可回落英文，但切换后页面必须正确显示且不出现布局错乱。

### RTL
- RTL 语言：阿拉伯语、波斯语、普什图语、乌尔都语、希伯来语、库尔德语（Sorani）。
- RTL 时：
  - 页面方向 `dir=rtl`，Header 导航顺序与按钮排列需要镜像。
  - 图标（如箭头/面包屑）需要按方向翻转。
  - 表单：标签与输入框对齐采用同一侧逻辑，避免左右混用。
  - 卡片与表格：保持视觉层级一致，避免强制 `text-left`。

### Meta Information
- 默认 Title 格式：`{页面名} | 呦鹿鸣汽车批量出口`（首页为品牌主标题）
- 默认 Description：突出“批量出口/热销车型/快速询盘”。
- Open Graph：`og:title`、`og:description`、`og:image`（使用站点默认分享图），`og:type=website`。

### Global Styles（Design Tokens）
- 背景色：`#0B1220`（深色背景）或 `#0F172A`；内容卡片：`#111827`；边框：`#243244`。
- 主色（CTA）：`#F59E0B`（琥珀/金色），Hover：`#D97706`。
- 强调色（标签）：热销 `#EF4444`；现货 `#22C55E`；新品 `#3B82F6`。
- 字体：中文优先系统字体（PingFang SC/微软雅黑），英文/数字可用 Inter。
- 排版：H1 36/44，H2 28/36，H3 20/28，正文 14-16/22-24。
- 按钮：主按钮实心（主色），次按钮描边（主色描边）；禁用态降低不透明度并禁用 hover。
- 表单：输入框 40px 高；错误提示红色；必填星号。

## 1）首页（/）
### Layout
- 结构为“纵向堆叠分区”，主视觉区用左右分栏（左文案右图片/轮播）。

### Meta
- Title：`呦鹿鸣汽车批量出口 | 热销车型库与批量询盘`
- Description：强调“面向海外采购商的批量出口服务、车型库、快速询盘”。

### Page Structure
1. 顶部导航（Sticky）
2. Hero 主视觉
3. 核心卖点/流程亮点
4. 热销车型推荐（卡片网格）
5. 快速询盘CTA区
6. 页脚（联系方式/邮箱/WhatsApp/版权）

### Sections & Components
- 顶部导航：Logo（左）+ 菜单（车型库/批量询盘/关于锚点）+ 右侧主CTA“获取批量报价”。
- Hero：
  - 标题：一句话价值主张（批量出口/稳定供给/快速响应）。
  - 3个要点 bullet（交付周期、可选条款、服务国家/港口）。
  - 主CTA：进入 `/inquiry`；次CTA：进入 `/models`。
  - 右侧展示：1张品牌场景图或车型轮播。
- 信任背书：资质/经验/合作模式（图标+短文案），避免过度承诺。
- 热销推荐：车型卡片（封面图、车型名、标签、价格区间/说明、按钮“查看详情/加入询盘”）。
- 快速询盘CTA：对比色背景条，强调“1分钟提交需求”。

## 2）热销车型库（/models）
### Layout
- 上方筛选条（横向Flex），下方列表Grid。
- 左侧可选“筛选面板”（桌面显示），移动端折叠为抽屉（可选）。

### Meta
- Title：`热销车型库 | 呦鹿鸣汽车批量出口`
- Description：突出“按品牌/能源/年份筛选，快速发起询盘”。

### Page Structure
1. 页面标题与摘要
2. 筛选/搜索区
3. 车型列表（Grid）
4. 询盘清单悬浮条（当已选择车型时）

### Sections & Components
- 筛选项（必要）：品牌、能源类型、年份、价格区间、关键词搜索、热销/上架开关。
- 车型卡片：
  - 封面图（16:9）、车型名、关键参数（2-3项）、标签（热销/现货）。
  - 操作：查看详情；“加入询盘”。
- 询盘清单条：显示已选车型数；按钮“去询盘”（跳 `/inquiry` 并携带车型ID列表）。

## 3）车型详情（/models/:id）
### Layout
- 顶部两列：左图集（轮播+缩略图），右侧信息卡（名称、标签、参数、CTA）。
- 下方使用 Tabs：参数/交付与条款/更多图片（可合并为分区）。

### Meta
- Title：`{车型名} | 批量出口车型详情`
- Description：车型关键参数 + 交付信息 + 询盘引导。

### Page Structure
1. 面包屑（首页/车型库/当前车型）
2. 图集 + 信息卡
3. 参数与交付信息
4. 关联车型（可选：同品牌/同级别）

### Sections & Components
- 信息卡：价格区间（若有）、交付周期说明（文本）、可选条款（从配置读取），主CTA“获取批量报价”。
- 参数区：用两列表格呈现（字段来自 `specs` JSON）。
- 关联车型：最多6个卡片，减少跳出。

## 4）询盘提交（/inquiry）
### Layout
- 左右分栏：左侧“你选择的车型/摘要”，右侧表单（桌面）；窄屏改为上下。

### Meta
- Title：`批量询盘 | 呦鹿鸣汽车批量出口`
- Description：结构化提交需求，获得报价与库存反馈。

### Page Structure
1. 标题与说明（预计响应时间/联系方式）
2. 已选车型摘要
3. 询盘表单
4. 提交成功确认（同页状态或跳转确认块）

### Sections & Components
- 车型摘要：列表显示车型名+数量输入（可选）；支持删除某车型。
- 表单字段（必填优先）：公司名称、联系人、邮箱、国家地区、目的港、总数量、意向条款、备注。
- 可选字段：WhatsApp、期望到港时间。
- 提交：
  - 提交中Loading态；失败提示（网络/校验）。
  - 成功态：显示询盘编号、下一步指引（“我们将通过邮箱/WhatsApp联系你”）。

## 5）管理后台（/admin）
### Layout
- 左侧侧边栏导航 + 右侧内容区（典型Dashboard）。

### Meta
- Title：`管理后台 | 呦鹿鸣`
- Description：内部管理页面（不做对外SEO）。

### Page Structure
1. 顶部栏（账号/退出）
2. 侧边栏（车型管理/询盘管理/基础配置）
3. 主内容（表格/表单/抽屉编辑）

### Sections & Components
- 登录态：未登录显示登录框（邮箱/密码）；成功后进入后台。
- 车型管理：
  - 列表表格（名称/品牌/热销/上架/更新时间）。
  - 新增/编辑表单（含 specs JSON 表单化输入可逐步增强）。
- 图片管理：上传多图、设置封面、排序。
- 询盘管理：
  - 列表（编号/公司/国家/状态/时间）。
  - 详情抽屉：询盘字段、关联车型、内部备注、状态流转。
- 基础配置：表单维护港口列表、条款文案、联系信息（存入 `site_config`）。
