# 页面设计：车系详情页（参数对比表改版｜Desktop-first）

## 1) Meta Information
- Title：{品牌名} {车系名} 参数对比
- Description：按年款分组对比该车系下不同车型的关键参数，并优先查看 VR。
- Open Graph：
  - og:title 同 Title
  - og:description 同 Description
  - og:type website

## 2) Global Styles（设计令牌建议）
- 背景色：#0B1220（深色）/ 内容卡片：#0F1A2B
- 文字：主文 #E6EEF9；次文 #9FB2CC；弱化 #6E86A6
- 强调色（主按钮/高亮）：#2F7CF6
- 描边：#23344D；分割线：rgba(255,255,255,0.08)
- 字体层级：
  - H1 28/36 SemiBold（车系名）
  - H2 18/26 Medium（分组标题/表头）
  - Body 14/22 Regular（参数值）
  - Caption 12/18（辅助说明）
- 按钮：
  - Primary：实底强调色；hover 加深；disabled 50% 透明
  - Secondary：描边；hover 背景轻微提亮
- 链接：默认强调色；hover 下划线

## 3) Layout
- 布局系统：桌面端 12 栅格 + 内容最大宽度 1200–1440px；页面整体纵向堆叠。
- 间距：区块之间 24–32px；卡片内边距 16–20px；表格行高 40–48px。
- 响应策略（简述）：
  - >=1280：对比表默认展示更多列宽；横向滚动主要用于车型列数量较多时。
  - <1024：对比表容器固定横向滚动；首列（参数名）保持可见。

## 4) Page Structure（从上到下）
1. 顶部导航（沿用全站）
2. 顶部 VR 优先展示区（Hero）
3. 车系基础信息区（标题/补充信息）
4. 年款分组导航（Tabs/分段控制器）
5. 横向参数对比表（无图片）
6. 页脚（沿用全站）

## 5) Sections & Components

### 5.1 顶部 VR 优先展示区（Hero）
- 结构：一个 16:9 容器（桌面建议高度 420–520px），置于首屏最上方内容区。
- 内容：
  - 主体：VR 播放/交互容器（若有 VR 资源则加载）。
  - 兜底：当 VR 不可用/加载失败，展示“VR 暂不可用”的占位卡片（不使用车型图片作为封面展示，保持“列表区无图片”的一致性）。
- 状态：
  - Loading：骨架屏（矩形占位 + 文案占位）。
  - Error：提示条 + 重试按钮。

### 5.2 车系基础信息区
- 左侧：H1 车系名（可包含品牌名）。
- 右侧：可放置简短辅助信息（如“参数对比”标签），不引入额外业务按钮。

### 5.3 年款分组导航
- 组件：Tabs/Segmented Control。
- 规则：按年款分组；默认选中最新年款。
- 行为：切换仅刷新对比表内容区域，页面不跳转。

### 5.4 横向参数对比表（核心区）
- 目标：车型作为“列”，参数项作为“行”，实现横向并列对比；不展示任何车型图片。

**表格容器**
- 外层：`overflow-x: auto` 的滚动容器；出现横向滚动条。
- 粘性元素：
  - 首列（参数名列）sticky left，始终可见。
  - 表头（车型名称行）sticky top（可选，确保长表滚动时仍能识别列）。

**表头（车型列标题）**
- 每列顶部展示：车型名称（name/fullname）。
- 不展示：封面图/缩略图/任何图片元素。

**表体（参数行）**
- 行结构：左侧为参数名，右侧为各车型对应参数值。
- 分组：参数可按逻辑分组块展示（如“车身尺寸/动力/续航”等），组标题为整行分隔条。
- 缺失值：统一用“—”。

**可用性细节**
- 长文本截断：车型名与参数值超出时省略号，hover 可 tooltip 显示全量。
- 视觉对齐：数值尽量右对齐或等宽字体展示（可选）提升可比性。

### 5.5 空状态
- 场景：
  - 当前年款无车型
  - 当前年款车型存在，但无可展示参数
- 表现：居中空状态卡片 + 返回入口（返回到上级页面）。
