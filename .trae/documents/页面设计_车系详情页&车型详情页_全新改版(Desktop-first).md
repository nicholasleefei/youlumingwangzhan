# 页面设计：车系详情页 & 车型详情页（Desktop-first，全新改版）

## 全局设计规范（两页通用）

### Layout
- 桌面优先：内容容器 `max-width: 1200px`（或 1280px），左右留白随视口扩展。
- 主布局：顶部导航（站点现有）+ 主内容区（Grid/Flex 混合）+ 页脚（站点现有）。
- 响应策略：
  - ≥1200：双栏/三栏信息结构（优先信息密度与对比效率）
  - 768–1199：关键模块保持双栏，图集与参数改为纵向堆叠
  - <768：按钮改为全宽；列表卡片由“左右结构”改为“上下结构”

### Meta Information（模板）
- Title：
  - 车系详情页：`{品牌名} {车系名} - 车型与出口报价`
  - 车型详情页：`{车型全称} - 参数/图集/出口报价`
- Description：优先取可用的车型/车系描述；否则使用默认模板（含“出口报价/参数/图集/询盘”关键词）。
- Open Graph：
  - `og:title` 同 Title
  - `og:description` 同 Description
  - `og:image` 使用车系头图或车型封面图

### Global Styles（全新视觉，不沿用现样式）
- 色彩（Design Tokens）
  - `--bg`: #F7F8FA（浅灰白底）
  - `--surface`: #FFFFFF（卡片底）
  - `--text-primary`: #111827
  - `--text-secondary`: #4B5563
  - `--border`: #E5E7EB
  - `--accent`: #2563EB（品牌蓝，主按钮）
  - `--accent-2`: #16A34A（成功/已选）
  - `--danger`: #DC2626（错误）
- 字体与排版
  - 字体：系统字体栈（中英文兼容）；标题更粗（600–700）。
  - 排版等级：H1 40/48，H2 24/32，H3 18/28，Body 14/22。
- 按钮
  - Primary：背景 `--accent`，hover 加深；disabled 降低不透明度。
  - Secondary：白底描边；hover 浅底。
  - Selected 状态：在按钮左侧显示“✓”，并改用 `--accent-2` 作为强调色。
- 链接
  - 默认使用 `--accent`；hover 下划线。
- 动效
  - hover/active 统一 150–200ms ease；图片切换 200ms 淡入淡出。

## 页面1：车系详情页（Series Detail）

### Page Structure
- 顶部信息区（Hero Banner）
- 车系内车型列表区（列表卡片）

### Sections & Components

#### 1) 顶部信息区（Hero Banner）
- 布局：CSS Grid（2列）
  - 左：品牌Logo（或品牌名首字母占位）+ 车系名称
  - 右：车系头图（16:9 或 21:9 裁切）
- 组件
  - `SeriesTitle`：品牌名 + 车系全称（无全称时用 name）
  - `SeriesMeta`（可选，仅展示已有字段）：如在售状态（salestate）/子公司（subcompany_name）
- 交互
  - 头图加载失败显示默认占位图；Logo 失败显示文字占位。

#### 2) 车型列表区（Model List）
- 布局：纵向列表，每条卡片为左右结构（Desktop）
  - 左：车型图（固定比例 4:3，contain）
  - 右：信息与操作
- 单条车型卡片（Model List Item）信息结构（从上到下）
  1. 车型名称（display_name）
  2. 关键参数网格（2列定义列表，按字段存在性展示：级别/马力/功率/续航/油耗/座位/能源类型等）
  3. 报价（FOB 区间或单值；无则“暂无报价”）
  4. 操作区：
     - 次按钮：查看详情（跳转到车型详情页）
     - 主按钮：加入询盘（可切换选择/取消）
- 交互
  - 卡片 hover：轻微抬升（shadow 增强）+ 边框高亮。
  - 加入询盘：点击后按钮即时变为“✓ 加入询盘”（保持可再次点击取消）。
  - 查看详情：打开车型详情页；返回后保持已选状态（依赖现有询盘草稿 store）。
- 状态
  - Loading：列表使用骨架屏（图块+3行文字+按钮占位）。
  - Empty：展示“当前没有车型数据”与返回入口。
  - Error：展示失败说明与返回入口。

## 页面2：车型详情页（Model Detail，Professional）

### Page Structure
- 顶部沉浸式主视觉（Hero）
- 报价与主CTA（加入询盘）
- 内容区 Tabs（参数/外观/内饰）
- 产品亮点 & 出口优势
- 底部固定操作条（返回/加入询盘）

### Sections & Components

#### 1) 顶部沉浸式主视觉（Hero）
- 布局：全宽背景图 + 前景信息覆盖（Flex column bottom）
- 内容
  - 热销标签（is_hot 为真时显示）
  - 车型主标题：fullname
  - 副标题：name（当 fullname 与 name 不同且都存在时）
  - 快速预览条：续航/功率/级别/座位（按字段存在性展示）
- 交互
  - 图片加载失败：显示大面积占位色块与“无图片”。

#### 2) 面包屑导航
- 布局：容器内单行（可换行）
- 交互：可返回首页/车型列表（保持现有路由）

#### 3) 核心报价与主CTA
- 布局：左右结构（Desktop）
  - 左：属性标签（brand / vehicle_class / energy_type / motor_type）
  - 右：主按钮“加入询盘”（大尺寸）
- 报价
  - 显示 FOB 报价（区间/单值）；无则“暂无报价”。
- 交互
  - 加入询盘：立即切换“✓”状态；按钮颜色/描边体现已选。

#### 4) Tabs 内容区（参数/外观/内饰）
- Tabs Bar
  - 桌面：水平三项，当前项下划线高亮。
  - 交互：点击切换内容；切换时内容区 200ms 淡入。
- 参数 Tab
  - 布局：三列卡片（动力性能/车身规格/性能充电），缺失分组不展示。
  - 无数据：显示“暂无参数数据”。
- 外观/内饰 Tab（图集）
  - 主图：16:9，contain；左右箭头按钮切换
  - 缩略图：6列网格；当前图高亮描边
  - 交互：
    - 点击缩略图跳转
    - 箭头循环切换（首尾衔接）

#### 5) 产品亮点 & 出口优势
- 布局：两列要点网格（Desktop）
- 内容：从 description 按行拆分为要点；为空则展示默认要点
- 交互：无（纯信息呈现）

#### 6) 底部固定操作条（Sticky CTA）
- 布局：容器内双按钮等分
  - 左：返回车型列表
  - 右：加入询盘
- 交互：滚动时始终可见，避免用户迷失与提升转化。
