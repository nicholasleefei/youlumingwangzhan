# 页面设计：后台「首页英雄区展示素材」（Desktop-first）

## 全局设计（适用于所有后台页面）
### Layout
- 桌面端优先：主体容器 `max-width: 1200px`，左右留白；栅格用 CSS Grid（12 列）+ 关键区域 Flex。
- 断点：≥1200（标准）、992–1199（紧凑）、<992（折叠为上下布局，表格变卡片列表）。

### Meta Information
- Title：后台管理 - 首页英雄区展示素材
- Description：管理首页英雄区图片/视频素材、排期与发布。
- Open Graph：后台页面默认 `noindex, nofollow`（避免被搜索引擎收录）。

### Global Styles / Tokens
- 背景：`#F7F7F8`（页面底）+ `#FFFFFF`（面板底）
- 文本：主文 `rgba(16,16,18,0.92)`，次文 `rgba(16,16,18,0.72)`
- 主色（唯一点缀色）：`#FF7E00`；危险：`#EF4444`
- 字体：系统字体栈；字号：12/14/16/20/24
- 按钮：Primary/Secondary/Ghost 三类；hover 提升亮度 + 轻微阴影；disabled 50% 透明
- 表单：输入框高度 36；错误提示红色小字 + 边框高亮

## 页面 1：登录页（/admin/login）
### Page Structure
- 居中卡片布局（Flex 垂直水平居中）。

### Sections & Components
1) 顶部品牌区
- Logo +「后台管理」标题。
2) 登录表单卡片
- 邮箱输入、密码输入（支持显示/隐藏）、登录按钮。
- 错误态：统一在按钮上方展示（如“账号或密码错误/无权限”）。
3) 会话提示
- 登录成功后跳转 `/admin/hero-assets`；若已登录直接跳转。

## 页面 2：英雄区展示素材管理页（/admin/hero-assets）
### Page Structure（桌面端）
- 顶部导航栏 + 2 列主体：左侧“素材库”，右侧“英雄区草稿配置与发布”。
- 主体使用 CSS Grid：`grid-template-columns: 5fr 7fr`，列间距 16。

### Sections & Components

#### A. 顶部导航栏（Sticky）
- 左侧：页面标题「首页英雄区展示素材」。
- 右侧：当前登录人（角色标签：Admin/Super Admin）+ 退出。
- 右侧状态灯：
  - 线上版本：`Vxx` + 发布时间
  - 当前草稿：editing

#### B. 左列：素材库（Asset Library）
1) 工具条
- 搜索框（按标题/来源/车型关键字）。
- 筛选：类型（图片/视频）、来源（上传/官图）、状态（草稿/已发布/已下线）。
- 主按钮：
  - 「上传素材」
  - 「从车型官图选择」
2) 素材列表（表格/卡片）
- 列：缩略图、类型、来源、标题、关联车型（若有）、状态、创建人/时间、操作。
- 行操作：编辑、下线（危险二次确认）。
3) 上传素材弹窗（Modal）
- 拖拽上传区 + 文件校验提示（仅图片/视频）。
- 表单：标题、alt、适配端（默认 Desktop）、备注。
- 上传进度条；完成后自动进入“素材编辑”态。
4) 官图选择弹窗（Drawer 优先，桌面更适合）
- 左侧：车型/车系筛选树或下拉。
- 右侧：官图网格（Card Grid）：缩略图、类型标签；支持多选。
- 底部：已选计数 +「加入素材库」。

#### C. 右列：英雄区草稿配置（Draft Config）
1) 草稿信息卡
- 草稿状态、最后修改时间、变更说明（提交时填写）。
- 编辑状态下：显示“自动保存/未保存”提示。
2) 展示位列表（Slots）
- 可配置 N 个展示位（默认 3–5，按实际产品要求）。
- 每个位为可折叠卡片：
  - 选择素材（从左侧素材库点选或在此处“选择”）
  - 文案：标题/副标题/按钮文案
  - 链接：跳转 URL（可选）
  - 排期：start/end（含快捷：立即生效/一周后下线）
  - 开关：启用/禁用
  - 排序：拖拽排序（桌面端）
3) 预览区
- 两个 Tab：草稿预览 / 线上预览。
- 预览容器固定比例（例如 16:9），叠加“安全区”参考线。

#### D. 发布区（Publish Panel）
- 管理员可见：
  - 「发布」按钮 + 变更说明输入框（可选但建议填写）
  - 发布后：生成新版本，首页立即生效

#### E. 发布历史与回滚（History）
- 折叠面板或右侧下方区域：版本列表（发布时间、发布人、说明）。
- 操作：查看详情、回滚（危险二次确认）。

### Interaction & States
- 锁定规则：无审核态；草稿始终可编辑；发布动作为“生成线上版本快照”。
- 校验：排期 end_at 必须 > start_at；视频必须有封面（如无则用首帧缩略图）。
- 反馈：所有关键动作（发布/回滚/下线）toast + audit log 记录。

### Responsive（<992）
- 两列变单列：先显示“草稿配置与发布”，素材库折叠为可展开区域。
- 表格转卡片；拖拽排序改为上下移动按钮。
