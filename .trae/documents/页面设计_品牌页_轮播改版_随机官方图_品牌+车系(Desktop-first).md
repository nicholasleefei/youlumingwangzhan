# 页面设计：品牌页轮播改版（Desktop-first）

## 全局（适用于本次改动涉及页面）
### Layout
- 桌面优先：内容区建议 1200–1440px 居中，左右留白。
- 主要布局：12 栅格（CSS Grid）+ 组件内部 Flexbox。
- 图片区域采用固定比例容器（如 16:9 或 4:3，具体按现有视觉规范），避免加载时布局跳动。

### Meta Information
- 品牌页 Title：{品牌名}｜品牌与车系
- 品牌页 Description：浏览 {品牌名} 旗下车系官方图片与详情。
- 车系详情图页 Title：{品牌名} {车系名}｜详情图
- Open Graph：og:title/og:description/og:image（优先使用该车系的官方图首图或本次随机图作为分享图）

### Global Styles（设计 Token 建议）
- 背景：#FFFFFF（或沿用站点背景色）
- 文字主色：#111827；次级文字：#6B7280
- 主按钮/强调色：沿用站点 brand color
- 圆角：卡片 12px；图片容器 12px（与卡片一致）
- 阴影：轻量投影（hover 时增强一档）
- 交互：hover 提升（阴影 + 轻微上浮 2px），focus-visible 明确描边

## 1）品牌页

### Page Structure
- 结构：顶部导航（沿用） + 主内容区。
- 主内容区优先展示“轮播区域”，其余品牌页内容保持不变。

### Sections & Components

#### A. 轮播区域（改版重点）
**组件：BrandSeriesCarousel**
- 位置：品牌页主内容区首屏或靠前位置（与当前品牌页布局一致）。
- 展示单位：一个“轮播卡片”代表一个品牌的一个车系入口。

**轮播卡片结构**
1. 图片层（主视觉）
   - 展示：该品牌对应车系的“随机官方图”1 张。
   - 加载：图片未就绪时显示 skeleton/灰阶占位；加载失败显示兜底图。
   - 可读性：图片上可加轻遮罩（例如 20–35% 黑色渐变）保证文字对比度。
2. 文案层（覆盖在图片下方或覆盖在图片底部）
   - 主文案：品牌名
   - 副文案：车系名
   - 合并展示形态：可用“品牌名 · 车系名”或两行排版（不改变文案语义）。
3. 点击热区
   - 整卡可点击（cursor: pointer）。
   - 点击行为：跳转到对应车系详情图页面。

**交互与状态**
- Hover：卡片阴影增强 + 图片轻微放大（scale 1.02，150–200ms）。
- Focus：键盘可聚焦，出现清晰 focus ring。
- 轮播控制：如站点已有左右箭头、分页点、拖拽切换则沿用现有交互，不新增额外交互要求。

**响应式（Desktop-first）**
- ≥1280px：轮播可视 3–4 张卡片（视现有组件能力）；卡片间距 16–24px。
- 768–1279px：可视 2–3 张。
- <768px：可视 1 张，左右滑动；文案字号适当下调。

## 2）车系详情图页面（承接页）

### Page Structure
- 顶部导航（沿用） + 面包屑（如现有） + 详情图内容区。

### Sections & Components
1. 标题区
   - 展示：{品牌名} {车系名}
2. 详情图内容区
   - 展示：车系详情图列表/画廊（沿用现有样式与能力）。
   - 若从轮播跳转：确保落地后首屏可见图片区域（避免落在页面中段）。

### 关键一致性要求
- 从品牌页轮播跳转后：URL 必须能唯一定位车系；页面根据该标识加载对应图片内容。
