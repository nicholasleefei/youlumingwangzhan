# 页面设计：物料资产管理-数据总览（Desktop-first）

## 1) Layout
- 桌面端优先：页面采用「顶部导航 + 面包屑 + 主内容区」结构。
- 主内容区使用 CSS Grid：`grid-template-columns: 1fr;`（单栏），核心树图占满可视区域；当树节点内容较宽时允许水平滚动。
- 间距：主区内边距 24px；模块间距 16px；节点行高建议 44–56px。

## 2) Meta Information
- Title: 数据总览 - 物料资产管理
- Description: 查看品牌/车系/车型维度的物料存在状态（VR/图片/参数）。
- Open Graph: title 同上；type=website（后台可不配置图片）。

## 3) Global Styles（设计令牌建议）
- 背景色：#F6F7FB（页面），卡片/容器：#FFFFFF
- 字体：14px/16px/20px（基础/强调/标题）
- 主色：#2563EB（操作、链接、焦点）
- 状态色（用于“状态栏”）：
  - 存在 present：#16A34A
  - 缺失 missing：#DC2626
  - 未知 unknown：#6B7280
- 交互：
  - 节点 hover：背景 #F3F4F6
  - 可点击元素 focus ring：2px 主色外发光

## 4) Page Structure
- 页面从上到下分为 3 区：
  1. 顶部：页面标题 + 面包屑
  2. 概览区：物料类型维度的状态汇总 + 图例（你用来快速理解颜色含义）
  3. 树形/思维导图区：品牌→车系→车型可展开结构，每个节点自带状态栏

## 5) Sections & Components

### 5.1 顶部区域
- 顶部导航：复用后台全局导航（不在本页面重复定义）。
- 面包屑：物料资产管理 / 数据总览。
- 页面标题：H1「数据总览」。

### 5.2 概览区（Summary + Legend）
- Summary 卡片（可横向排列）：按物料类型展示 3 个计数：存在/缺失/未知。
  - 物料类型固定：外观VR、内饰VR、官图、外观图、内饰图、详细参数。
  - 计数口径：默认以“当前已加载层级内的节点集合”统计（例如首次仅品牌层；展开后统计范围随加载数据扩大）。
- Legend：展示三种状态色块 + 文案（存在/缺失/未知）。

### 5.3 树形/思维导图区（核心）
- 容器：白底卡片，标题「品牌/车系/车型结构」。
- 树节点（Node Row）结构（从左到右）：
  1) 展开/收起控件：品牌与车系节点显示；车型节点不显示。
  2) 节点名称：显示品牌/车系/车型名；过长时省略号；hover 显示完整名称 tooltip。
  3) 层级标签：Badge（品牌/车系/车型），用于快速识别层级。
  4) 状态栏（Status Bar）：一行“物料类型胶囊/小条”组件，按固定顺序展示：
     - 外观VR | 内饰VR | 官图 | 外观图 | 内饰图 | 详细参数
     - 每个胶囊用颜色表示 present/missing/unknown，并在悬停时显示文本（如“外观VR：缺失”）。
     - 交互：点击胶囊打开状态编辑 Popover（存在/缺失/未知）；选择后自动保存并提示。
- 多选：节点行支持选中态高亮；按 Ctrl/⌘ 多选，Shift 连选。
- 右键菜单：在节点上右键打开菜单，菜单作用于当前已选集合。
  - 批量修改：节点状态（正常/不显示/不可用），物料状态（存在/缺失/未知）。
  - 批量删除：外观VR、内饰VR、官图、外观图、内饰图（对车型/车系/品牌按适用性启用或置灰）。
- 删除确认：批量删除/单项删除前弹出确认对话框，说明不可恢复。
- 缩进：品牌 0；车系 24px；车型 48px（或基于树组件自动计算）。
- 加载/错误：
  - 节点展开加载子节点时，节点下方显示轻量加载态。
  - 加载失败时在该节点下方显示错误提示与“重试”。
- 空态：当品牌数据为空时展示说明文案（如“暂无品牌数据”）。

### 5.4 响应式行为（补充）
- >= 1200px：状态栏完整显示；不足时节点行允许横向滚动。
- < 992px：状态栏可自动换行到第二行（同节点内），保证可读性。

### 5.5 可访问性与一致性
- 展开/收起按钮支持键盘操作（Enter/Space）；状态胶囊提供 aria-label（如“外观VR 状态 缺失”）。
- 状态不可只靠颜色区分：胶囊内或 tooltip 必须显示文字状态
- 右键菜单提供键盘替代入口：节点行的“更多”按钮（⋯）在聚焦时可打开同等菜单。
