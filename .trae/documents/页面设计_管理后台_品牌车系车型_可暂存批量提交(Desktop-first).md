# 页面设计说明（Desktop-first）

## 全局设计（适用于所有页面）

### Layout
- 桌面优先：内容最大宽度 1200–1440px，居中；后台主内容区使用 **CSS Grid + Flexbox** 组合。
- 断点建议：
  - ≥1200px：三段式（顶部栏 + 左侧视图导航/筛选 + 右侧表格区）。
  - 768–1199px：左侧栏收起为可展开 Drawer。
  - <768px：仅保证可用（表格改为卡片列表 + 编辑弹窗）。

### Meta Information
- 默认 Title：`管理后台 - 车型数据管理`
- Description：`品牌/车系/车型/车型详情的增删改查与批量提交`
- Open Graph：
  - og:title 同 Title
  - og:description 同 Description
  - og:type: website

### Global Styles（设计 Token 建议）
- 背景：`--bg: #0B1220`（深色后台）或 `#F6F7FB`（浅色后台，二选一）
- 内容卡片：`--surface: #FFFFFF`
- 主色：`--primary: #2563EB`
- 危险色：`--danger: #DC2626`
- 成功色：`--success: #16A34A`
- 边框：`--border: #E5E7EB`
- 字体：
  - 标题：16/18/20
  - 正文：14
  - 辅助：12
- 按钮：
  - Primary：实心主色；hover 加深 8%
  - Secondary：描边；hover 背景淡灰
  - Danger：危险色；用于删除/清空草稿
- 链接：主色下划线 hover
- 表格：行 hover 高亮；脏数据行左侧加色条标记

### Page Structure
- 居中单卡片布局（Card + 表单），页面背景可轻量渐变或纯色。

### Sections & Components
1. 顶部品牌区
   - Logo + “管理后台”标题
2. 登录表单卡片
   - 输入框：邮箱、密码
   - 操作：登录（Primary）

- Enter 提交
- 登录成功后自动跳转 `/admin/vehicle-data`

## 页面 2：数据管理页（/admin/vehicle-data）

### Page Structure
- 顶部固定 Header + 主体两栏（左：视图与筛选；右：表格与编辑区）。
- 主体区采用 CSS Grid：
  - 左栏 280px（可折叠）
  - 右栏自适应

### Sections & Components

#### A. 顶部 Header（固定）
- 左侧：页面标题 `车型数据管理`
- 中部：环境/库标识（可选，仅展示）
- 右侧：
  - “草稿(未提交) N”按钮（Primary/带徽标）
  - 退出登录

#### B. 左侧栏：视图导航 + 级联筛选
1. 视图切换 Tabs / Segmented Control（四项）
   - 品牌
   - 车系
   - 车型
   - 车型详情
2. 级联筛选区（随视图变化）
   - 在车系视图：品牌下拉（单选）
   - 在车型视图：品牌下拉 + 车系下拉（依赖选择）
   - 在车型详情视图：品牌下拉 + 车系下拉 + 车型下拉
3. 快速搜索
   - 关键字输入（name/code）
4. 重置按钮
   - 清空筛选与搜索（不影响草稿）

#### C. 右侧主区：表格列表（查 + 改 + 删 + 增）
1. 工具条
   - 新增（Primary）
   - 刷新（Secondary）
   - 排序选择（下拉）
   - 分页信息（当前页/总数）
2. 数据表格
   - 列：按实体展示必要字段（name/code/is_active/sort_order/updated_at 等）
   - 行状态：
     - 新增未提交：整行淡色底 + “NEW”标记
     - 已修改未提交：左侧色条 + “EDITED”标记
     - 已标记删除：整行置灰 + 删除线 + “TO DELETE”
   - 行操作：编辑、删除、撤销（仅对未提交变更出现）
3. 行内编辑/弹窗编辑
   - 简单字段（文本、数字、开关）支持行内
   - 复杂字段（specs JSON）用弹窗编辑器（textarea + JSON 校验提示）

#### D. 草稿区（本地暂存）— 右侧 Drawer / 底部 Panel
- 触发：点击 Header 的“草稿 N”
- 内容：
  1) 概览：本次未提交变更数、按实体分组数量
  2) 变更列表：每条变更显示
     - 实体类型 + 操作类型（新增/修改/删除）
     - 主键/临时键
     - 字段 diff（建议：只显示变更字段）
  3) 操作：
     - 撤销单条
     - 撤销全部（Danger）
     - 确认提交（Primary）

#### E. 提交确认弹窗（Confirm Modal）
- 文案：
  - “将一次性提交 N 条变更到数据库，是否继续？”
- 操作：取消 / 确认
- 提交中：显示进度与不可编辑遮罩

#### F. 提交结果区（在草稿区内展示）
- 成功：显示“已提交成功”并提供“清空草稿/关闭”
- 失败：
  - 列表展示失败项与原因
  - 保留失败项在草稿中，允许你修正后再次确认

### 关键交互规范（与你的需求强绑定）
- **默认不落库**：所有增删改先写入草稿，直到点击“确认”才写库。
- **切换视图不丢草稿**：草稿是跨四个视图共用的。
- **撤销必须可用**：对新增/修改/删除均可撤销到提交前状态。
- **提交后刷新**：提交成功后自动刷新当前视图列表；若有 tempId->id 映射，需更新本地行。

### 空状态/异常状态
- 空列表：引导“调整筛选或新增记录”。
- 网络错误：Toast + 重试。
- 提交失败：在结果区展示可操作错误（例如字段校验失败/冲突/权限不足）。

### 可用性细节（桌面优先）
- 表格支持固定表头与横向滚动（字段较多时）。
- 草稿 Drawer 宽度 420–520px，便于审阅 diff。
