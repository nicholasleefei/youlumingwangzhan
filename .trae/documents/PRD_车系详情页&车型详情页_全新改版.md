## 1. Product Overview
为「车系详情页」与「车型详情页」进行一次完全重做的改版，在不改变现有业务能力（查看/浏览/加入询盘）的前提下，重构信息结构与交互节奏，提升车型发现效率与询盘转化。

## 2. Core Features

### 2.1 Feature Module
本次改版需求由以下页面构成：
1. **车系详情页**：车系头图与身份信息、车型列表（核心参数与报价）、车型详情跳转、加入询盘。
2. **车型详情页**：车型主视觉、核心报价与加入询盘、参数/外观/内饰切换、图集浏览、产品亮点&出口优势、返回列表。

### 2.2 Page Details
| Page Name | Module Name | Feature description |
|---|---|---|
| 车系详情页 | 页面加载与异常处理 | 展示加载态；加载失败/无数据时展示错误态与返回入口 |
| 车系详情页 | 车系头部信息区（Hero） | 展示品牌名+车系名；展示头图（品牌Logo或默认图） |
| 车系详情页 | 车型列表（纵向列表卡片） | 列出该车系下所有车型；每条车型展示：封面图、车型名、关键参数（如级别/马力/功率/续航/油耗/座位/能源类型等按数据存在性展示）、FOB报价 |
| 车系详情页 | 车型条目交互 | 点击“查看详情”进入车型详情页；点击“加入询盘”对该车型进行选择/取消选择，并在按钮上体现已选状态（✓） |
| 车系详情页 | 空数据提示 | 当车系下无车型时展示空状态，并提供返回入口 |
| 车型详情页 | 页面加载与异常处理 | 展示加载态；加载失败/车型不存在时展示错误态与返回入口 |
| 车型详情页 | 顶部主视觉（Hero） | 展示车型主图（封面）；展示热销标记（若存在）；展示车型名称（优先fullname，其次name） |
| 车型详情页 | 快速预览条（关键参数） | 按数据存在性展示关键参数（如续航/功率/级别/座位数）；用于快速建立车型轮廓 |
| 车型详情页 | 面包屑导航 | 提供从首页/车型列表回到上级页面的路径导航 |
| 车型详情页 | 核心报价与主CTA | 展示FOB报价（区间或单值，无则“暂无报价”）；提供“加入询盘”主按钮并体现已选状态（✓） |
| 车型详情页 | 内容切换（Tabs） | 提供“车型参数 / 外观图集 / 内饰图集”三项切换；切换仅影响内容区，不刷新页面 |
| 车型详情页 | 车型参数（卡片化分组） | 以分组卡片展示参数：动力性能、车身规格、性能充电；仅展示数据存在字段；无任何参数时展示“暂无参数数据” |
| 车型详情页 | 图集浏览（外观/内饰） | 支持主图浏览（上一张/下一张）；支持缩略图点击跳转；当图片不足时使用兜底图片集 |
| 车型详情页 | 产品亮点 & 出口优势 | 将车型描述按行拆分为要点列表展示；无描述时使用默认要点文案 |
| 车型详情页 | 底部固定操作条 | 提供“返回车型列表”“加入询盘”两个按钮，滚动时保持可用 |

## 3. Core Process
**访客浏览与询盘转化流程**
1) 你从品牌/车型列表进入某个车系详情页。
2) 你在车系详情页浏览车型列表，查看每个车型的关键参数与报价。
3) 你可对多个车型点击“加入询盘”进行勾选，或点击“查看详情”进入车型详情页深入了解。
4) 在车型详情页，你通过 Tabs 查看参数/外观/内饰，并在任意位置点击“加入询盘”完成选择。
5) 你点击“返回车型列表”回到列表继续选型（询盘选择状态保持）。
