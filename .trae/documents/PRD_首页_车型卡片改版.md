## 1. Product Overview
首页「车型卡片」信息结构与布局改版：卡片改为一行一个、名称不截断、展示品牌/车系/关键参数，并隐藏厂商指导价。
面向浏览首页车型列表的用户，提升信息可读性与对比效率。

## 2. Core Features

### 2.1 Feature Module
本次需求由以下页面组成：
1. **首页（车型列表）**：车型卡片列表、一行一个卡片布局、卡片字段展示规则。

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|---|---|---|
| 首页（车型列表） | 列表布局 | 将车型卡片布局改为「一行一个」；卡片宽度随容器自适应（桌面端优先）。 |
| 首页（车型列表） | 车型名称展示 | 展示完整车型名称，不使用省略号截断；超长名称允许换行并自适应卡片高度。 |
| 首页（车型列表） | 品牌/车系信息 | 在卡片主信息区展示「品牌 + 车系」（来源于现有车型数据字段）。 |
| 首页（车型列表） | 关键参数展示 | 在卡片信息区展示关键参数（从现有车型数据中选取若干项，建议 3–5 项）；缺失参数时自动隐藏对应项并保持布局稳定。 |
| 首页（车型列表） | 隐藏厂商指导价 | 首页车型卡片不展示「厂商指导价」相关字段（包含标签、数值、辅助说明/Tooltip 等）。 |
| 首页（车型列表） | 状态与容错 | 列表加载中展示骨架/占位；无数据展示空态；接口失败展示错误态与重试入口（如项目现有交互已定义则沿用）。 |

## 3. Core Process
用户流程：
1. 你进入首页后浏览车型列表。
2. 你逐条查看车型卡片：可完整阅读车型名称，并同时看到品牌/车系与关键参数。
3. 你在首页不会看到厂商指导价信息。
