# 页面设计：资源配置-总览表（Desktop-first）

## 1) Layout
- 桌面端优先：页面主体最大宽度 1200–1440px，内容区居中；左右留白自适应。
- 管理后台通用布局：左侧侧边栏（一级导航）+ 顶部栏（面包屑/账号）+ 内容区。
- 内容区采用纵向堆叠：筛选区（卡片）→ 指标概览（可选，若已有则复用）→ 表格区。
- 表格区域使用 CSS Grid + Table 混合：表头固定（sticky），内容滚动；行高 48px。

## 2) Meta Information
- Title: 资源配置总览表 - 管理后台
- Description: 按品牌/车系汇总 VR 与图片资源存在情况及分类统计，支持表格内删除管理。
- Open Graph: title/description 同上；url 指向 /admin/resource/overview。

## 3) Global Styles
- 背景色：#F7F8FA（后台浅灰底）
- 内容卡片：白底 #FFFFFF，圆角 12px，阴影轻微（0 2px 8px rgba(0,0,0,0.06)）
- 主色：#1677FF（按钮/高亮）
- 危险色：#FF4D4F（删除/警告）
- 字体：
  - 标题 20/24px，半粗
  - 正文 14/20px
  - 辅助 12/18px
- 按钮：
  - Primary：主色底白字；hover 加深 8%
  - Danger：危险色；hover 加深 8%；禁用态 40% 透明
- 链接：主色；hover 下划线

## 4) Page Structure
### 4.1 顶部栏
- 面包屑：管理后台 / 资源配置 / 总览表
- 右侧：当前账号信息 + 退出

### 4.2 筛选区（卡片）
- 左到右排列（桌面端单行）：
  1) 品牌选择（下拉/可搜索）
  2) 车系选择（下拉/可搜索；联动品牌）
  3) 关键字搜索（品牌/车系）
  4) 操作按钮：查询、重置
- 辅助信息：展示“当前筛选结果共 N 行”。

### 4.3 聚合表格区（核心）
- 表格列（建议最小集合，可按你现有口径微调）：
  - 品牌
  - 车系
  - 车型数
  - VR：状态（有/无）+ 数量
  - 图片：状态（有/无）+ 数量
  - 图片分类统计：以 Tag/小型条形分布展示（分类来自系统现有分类；过多时折叠“更多”）
  - 操作：删除 VR、删除图片

- 单元格展示规则：
  - “有/无”用状态点：绿色=有、灰色=无；数量为 0 时显示 0。
  - 分类统计：默认展示 Top 3 分类 + “+X”；悬浮 Tooltip 展示完整分类列表与数量。

### 4.4 行内删除交互
- 删除入口：仅对有权限用户显示；无权限隐藏整列或置灰并提示。
- 点击“删除 VR/删除图片”后弹窗确认（Modal）：
  - 标题：确认删除资源？
  - 文案：说明删除影响（例如：将删除该品牌/车系范围内对应资源；若你的实际删除粒度更细，可在此处改为“将删除所选资源”）。
  - 二次确认：输入“DELETE”或勾选“我已了解不可恢复”（二选一，按你产品安全级别选）
  - 按钮：取消（默认）/ 确认删除（Danger）
- 成功反馈：Toast 提示“删除成功”，并自动刷新当前行聚合数据。
- 失败反馈：Toast 展示失败原因（无权限/对象不存在/网络错误）。

### 4.5 状态设计
- 加载态：表格骨架屏（10 行）
- 空态：插画 + 文案“暂无数据”，提供“重置筛选”按钮
- 错误态：错误提示条 + “重试”按钮

## 5) Responsive Behavior（补充）
- >=1200px：筛选区单行、表格完整展示。
- 768–1199px：筛选区自动换行；表格允许横向滚动；操作列固定在最右侧（sticky right）。
- <768px（若需要支持）：建议仅保留筛选与关键列，更多列折叠到行展开面板（可选）。
