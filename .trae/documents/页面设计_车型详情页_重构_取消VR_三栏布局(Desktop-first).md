# 页面设计：车型详情页（重构，Desktop-first）

## 1) Layout（布局）
- 桌面端优先：三栏布局（左侧车型列表 / 中间图片 / 右侧参数对比）。
- 布局方式：CSS Grid 为主，必要处辅以 Flex。
  - Grid：`grid-template-columns: 280px minmax(640px, 1fr) 360px`（可按实际容器宽度微调）。
  - 栅格间距：24px；页面内卡片间距：16px。
- 滚动策略：页面整体纵向滚动；右侧参数区在桌面端可设置 `position: sticky; top: 88px`（避免遮挡导航）。
- 响应式（仅原则，非移动端优先）：
  - < 1200px：右侧参数区降为下方折叠区（仍保持≤12项）。
  - < 992px：左侧车型列表变为顶部下拉/横向滚动列表。

## 2) Meta Information（页面元信息）
- Title：`{车型名} - 车型详情`
- Description：`查看{车系名} {车型名}图片与主要参数对比（≤12项）。`
- Open Graph：
  - `og:title` 同 Title
  - `og:description` 同 Description
  - `og:image` 使用当前车型主图 URL（若无则使用站点默认图）

## 3) Global Styles（全局样式与设计令牌）
- 背景色：`#F7F8FA`
- 内容卡片：白底 `#FFFFFF`，圆角 12px，阴影 `0 6px 20px rgba(0,0,0,0.06)`
- 文本：
  - 标题：20/24/28（分级）
  - 正文：14/16
  - 辅助：12/14，颜色 `#6B7280`
- 主色（强调色）：延用站点品牌色（若未定义，临时用 `#2563EB`）
- 按钮：
  - Primary：实心主色，hover 加深 8%
  - Secondary：描边主色，hover 背景浅主色 6%
- 链接：默认主色，下划线仅在 hover 出现

## 4) Page Structure（页面结构）
1. 顶部区域：面包屑 + 车型标题（车系名 / 车型名 / 年款等必要信息）。
2. 主体三栏区域：
   - 左栏：同车系车型列表（切换入口）。
   - 中栏：图片展示（主图为核心）。
   - 右栏：主要参数对比（≤12项）。

## 5) Sections & Components（区块与组件）

### 5.1 顶部：标题与导航区
- 组件：Breadcrumb、Page Title
- 层级：
  - Breadcrumb：`品牌（可选） / 车系 / 车型`
  - Title：车型名（H1）
  - SubTitle（可选）：年款/配置简述
- 状态：加载时显示标题骨架屏。

### 5.2 左侧：同车系车型列表（车型切换）
- 容器：卡片式列表，支持内部滚动（长列表）。
- 列表项：
  - 主文案：车型名
  - 次文案：年款/配置（若有）
  - 状态：选中态（高亮底色 + 左侧色条）；hover 态（浅底）
- 交互：
  - 点击列表项：切换当前车型（驱动中栏与右栏刷新）。
  - 加载态：列表骨架屏；失败态：错误提示 + 重试按钮。

### 5.3 中间：图片展示区
- 目标：清晰展示当前车型图片（替代原 VR）。
- 结构：
  - 主图区域（16:9 或 4:3，自适应容器）
  - 缩略图条（可选，但需能切图；也可用“上一张/下一张”替代）
- 交互与状态：
  - 点击缩略图：更新主图。
  - 图片加载失败：显示占位图 + “重试”。
  - 图片为空：显示空状态（无图片）。

### 5.4 右侧：主要参数对比区（≤12项）
- 容器：卡片；桌面端 sticky。
- 标题：`主要参数对比`（副标题可提示“最多展示12项”）。
- 内容形态（建议）：对比表格/对比列表（二选一，保证可读性即可）。
  - 行：参数项（label）
  - 列：当前车型为默认主列；对比对象为同车系其它车型（数据源同左侧列表）
- 约束：
  - 参数项数量不超过 12（固定白名单 key，或后端已筛选则直接渲染）。
  - 缺失值统一显示 `-`。
- 状态：
  - 加载态：表格骨架。
  - 失败态：错误提示 + 重试。

## 6) 关键可用性细节（必需）
- 切换车型时：左侧选中态立即变化；中栏与右栏显示“局部加载态”，避免整页闪烁。
- 信息密度控制：右侧对比区默认只展示≤12项，确保首屏可扫读。
- 可访问性：列表项与切换控件可键盘聚焦；选中态具备颜色+形状双重提示。
