# 页面设计：车型详情页（Desktop-first）

## 全局设计规范（适用于本文所有页面）
### Layout
- 桌面优先（≥1200px）：内容区最大宽度 1200–1320px，左右留白自适应；主内容采用 12 栏 Grid。
- 平板（768–1199px）：改为 8 栏 Grid，媒体区与参数区可上下堆叠。
- 移动端（≤767px）：单列堆叠；图片预览与参数弹窗全屏。

### Meta Information（默认）
- Title 模板：{车型名} - 车型详情
- Description：展示{车型名} 360/内饰VR、官方图/实拍图与参数信息，并支持导出PDF。
- Open Graph：og:title/og:description 同上；og:image 取车型主图（官方图首图或封面）。

### Global Styles / Tokens
- 字体：系统字体栈（优先 PingFang SC / Microsoft YaHei），标题 24/20/18，正文 14/16。
- 颜色：
  - 背景：#0B1220（深色站点背景）或 #F7F8FA（浅色内容背景，二选一与现有站点一致）
  - 卡片：#FFFFFF（浅）/ #111827（深）
  - 主色：#2563EB（按钮/链接）
  - 辅助：#64748B（次级文字）
  - 分割线：#E5E7EB
- 按钮：
  - Primary：主色底 + 白字；hover 加深；disabled 降低不透明度
  - Secondary：描边/浅底；hover 提升对比
- 链接：主色文字 + hover 下划线
- 动效：切换媒体/打开弹窗 150–200ms ease-out；避免复杂动画影响媒体性能

## 页面 1：车系详情（含车型卡片）
### Layout
- 顶部：站点导航（复用全站 Header）。
- 内容区：两段式纵向布局（车系信息卡 + 车型卡片网格）。

### Page Structure
1. 顶部导航/面包屑
2. 车系信息卡片（标题、简要说明/封面图，字段以数据源为准）
3. 车型卡片网格（3–4 列，间距 16–24px）

### Sections & Components
- 面包屑：Home / 品牌 / 车系（可选），提供返回路径。
- 车型卡片（Model Card）：
  - 元素：车型图、车型名、基础标签（如年份/配置名，若有）、“查看详情”按钮或整卡可点击。
  - 交互：点击后打开车型详情
    - 跳转模式：进入 /models/:modelId
    - 弹窗模式：在当前页上方打开详情弹窗（背景遮罩，保留滚动位置）

## 页面 2：车型详情（支持“弹窗/跳转”两种容器）
> 说明：当以“弹窗”呈现时，页面结构保持一致，只是外层容器变为 Modal（居中大弹窗或右侧抽屉皆可，推荐居中大弹窗，便于媒体展示）。

### Layout
- 桌面端：左右双栏布局
  - 左：媒体区（约 7/12 宽）
  - 右：信息与参数区（约 5/12 宽）
- 平板/移动：上下堆叠（媒体在上，参数在下）

### Meta Information
- Title：{车型名} - 车型详情
- Canonical：跳转模式使用 /models/:modelId；弹窗模式可不单独设置或用同一路由+参数

### Page Structure
1. 顶栏（标题 + 返回/关闭 + 导出PDF）
2. 主体双栏
   - 左：360/内饰VR切换区 + 媒体展示
   - 右：车型关键信息 + 重点参数 + 查看全部参数入口
3. 下方：官方图分区、实拍图分区（可在左栏下继续纵向延展，或全宽分区）

### Sections & Components
#### 2.1 顶栏（Header Bar）
- 左侧：
  - 返回（跳转模式）或关闭（弹窗模式）
  - 标题：车型名（可附车系名/配置名作为副标题）
- 右侧：主按钮“导出PDF”
  - 状态：默认/生成中（loading）/失败重试

#### 2.2 360 / 内饰 VR 切换区（核心）
- 组件：Segmented Tabs（两个选项）
  - Tab1：360 外观
  - Tab2：内饰 VR
- 展示框（16:9 或 4:3，自适应）：
  - 360 外观：
    - 最小实现：拖拽/滑动切帧（图片序列）
    - UI：加载骨架屏；拖拽提示；全屏（可选，若实现成本可控）
  - 内饰 VR：
    - 最小实现：全景图可拖拽观看
    - UI：加载骨架屏；重置视角按钮
- 异常态：无资源/加载失败时显示占位图 + “重试”

#### 2.3 官方图 / 实拍图分区
- 分区标题：官方图、实拍图（两段独立）
- 展示方式：
  - 桌面：3–4 列缩略图网格
  - 点击缩略图：打开图片预览 Lightbox（遮罩层）
  - 预览内：左右切换、关闭、当前序号
- 空态：无对应图片时显示“暂无图片”占位

#### 2.4 重点参数区 + 查看全部参数
- 重点参数区（右栏上半）：
  - 卡片式列表：每行“参数名 - 参数值（单位）”
  - 数量：建议 6–12 条（由 is_highlight 控制）
- “查看全部参数”入口：
  - 位置：重点参数区底部
  - 样式：次按钮/文本链接

#### 2.5 查看全部参数弹窗（Modal）
- 容器：居中弹窗（桌面宽 860–960px，高度 70–80vh，可滚动）
- 顶部：标题“全部参数 - {车型名}” + 关闭按钮
- 内容：
  - 按组展示（group_name）：每组一个可折叠面板或分段标题
  - 每组内为两列或单列参数表（桌面两列更紧凑）
- 底部：关闭按钮（可选，若右上关闭足够可省略）

#### 2.6 导出 PDF（交互与内容边界）
- 触发：点击“导出PDF”
- 导出内容建议（与PRD一致，按模块拼接）：
  1) 车型标题与基础信息
  2) 媒体区（当前Tab的截图/首帧）
  3) 官方图/实拍图（建议各取首图或前N张缩略图，避免PDF过大）
  4) 重点参数
  5) 全部参数（与弹窗同结构）
- 注意：
  - 导出中禁止重复点击
  - 失败提示原因（如跨域图片导致截图失败）并提供重试
