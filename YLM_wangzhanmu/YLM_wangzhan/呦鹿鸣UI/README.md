# Youluming - Professional Auto Export Website

高端UI升级版 呦鹿鸣专业汽车出口外贸官网

## 设计特色

- **配色体系**: 深邃炭灰+海洋蓝为主色调，低饱和高级配色，符合国际商务审美
- **排版系统**: 清晰的字体层级，规范的字重、行高和间距系统
- **质感升级**: 精致卡片、分层阴影、渐变光影、圆角设计
- **交互优化**: 滚动渐入动画、悬浮微交互、平滑过渡
- **完整响应式**: 完美适配桌面端、平板、移动端

## 技术栈

- React 18
- Vite
- CSS Modules 组件化样式

## 安装运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```
