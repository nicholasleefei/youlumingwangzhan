# 需求文档：汽车之家车型物料爬虫工具（Web 内部工具）

## 1. 背景与目标

运营团队手动下载汽车之家车型物料耗时高（单次新车发布约 100 小时），且图片质量不稳定（分辨率不够/有水印/不全）。本工具目标将单款车型物料下载时间降至约 10 小时量级，并保证输出为高清原图、按约定目录结构打包成 ZIP。

## 2. 术语

- 车系：汽车之家以数字 ID 标识的车系页面，例如 `https://www.autohome.com.cn/{车系ID}/`。
- 物料类型：外观图、内饰图、细节图、外观 360VR、内饰 360VR、品牌官方图。
- 任务：一次“对某个车系进行全量物料抓取并打包”的后台执行单元。

## 3. 范围（V1）

### 3.1 必做能力

1. 车系输入
   - 方式 A：输入“品牌 + 车型官方名称”进行搜索，返回车系列表供选择。
   - 方式 B：直接输入车系 ID（数字）。
2. 一键下载
   - 选择车系后可开始下载全部物料类型。
3. 进度展示
   - 展示实时进度：当前类型、已完成/总数（按文件或按步骤）、成功/失败数量。
4. 结果下载
   - 完成后提供 ZIP 下载。
   - ZIP 解压后目录结构必须符合约定（见 3.3）。

### 3.2 不做（Non-Goals）

- 不支持懂车帝、易车等其他网站。
- 不做定时自动检测新车发布（仅人工触发）。
- 不做用户权限管理（内部工具默认可用）。
- 不做图片智能筛选/去重（下载所有可用物料）。

### 3.3 ZIP 目录结构（验收）

解压后根目录包含：

- `01_外观图/`
- `02_内饰图/`
- `03_细节图/`
- `06_外观360VR/`
- `07_内饰360VR/`
- `08_品牌官方图/`

360VR 目录规则：

- `06_外观360VR/` 与 `07_内饰360VR/` 下按颜色建立子目录。
- 子目录名称包含色号信息（例如 `珠光白_#FFFFFF`）。
- 该颜色下所有 360VR 序列图均放在对应颜色子目录。

## 4. 用户流程（V1）

### 4.1 流程 A：搜索并选择车系（推荐）

1. 用户输入“品牌 + 车型官方名称”。
2. 点击“搜索车系”，展示前 3~10 条结果（名称、车系 ID、厂商/级别等辅助信息）。
3. 用户选择正确车系。
4. 点击“开始下载”，进入进度页。
5. 完成后进入结果页并下载 ZIP。

### 4.2 流程 B：直接输入车系 ID（备选）

1. 用户输入车系 ID（数字，例如 5769）。
2. 点击“开始下载”，进入进度页。
3. 完成后进入结果页并下载 ZIP。

## 5. 功能性需求（FR）

### 5.1 首页

- 支持两种输入方式（A/B）。
- 方式 A：
  - 支持输入框（品牌+车型）。
  - 点击搜索后展示列表供选择。
  - 选择后显示已选车系信息。
- 方式 B：
  - 支持输入车系 ID（数字校验）。
- “开始下载”按钮：
  - 只有在选定车系或输入合法车系 ID 时可用。

### 5.2 进度页

- 显示任务基本信息：车系名称/ID、开始时间。
- 显示实时进度：
  - 当前阶段（解析链接/下载外观图/下载 360VR 等）。
  - 计数：已完成/总数（可按文件或按步骤统计）。
  - 错误列表（仅展示摘要）。
- 支持刷新恢复（页面刷新后可继续查看该任务进度）。

### 5.3 结果页

- 展示统计：成功文件数、失败文件数、耗时。
- 提供 ZIP 下载链接。
- 若失败：展示失败原因摘要并允许重新开始（新任务）。

## 6. 非功能性需求（NFR）

- 可用性：普通浏览器可用，界面简洁。
- 稳定性：网络抖动可重试；任务失败需有清晰错误提示。
- 性能：支持大批量下载（可能数千图片）；应限制并发以避免过载。
- 安全：不在前端暴露任何服务端敏感信息；仅抓取公开页面资源。
- 可维护：爬虫关键选择器/解析逻辑可集中管理，便于网站改版时调整。

## 7. 验收清单（面向 V1）

- 能通过“品牌+车型”搜索并选择车系。
- 能直接输入车系 ID 并开始任务。
- 能实时查看任务进度（含当前阶段与计数）。
- 能下载 ZIP 且目录结构符合 3.3。
- 下载图片为高清原图、无水印（以汽车之家提供的原图链接为准）。
