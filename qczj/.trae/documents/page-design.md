# 页面设计：汽车之家车型物料爬虫工具（Web）

## 1. 页面清单

- `/` 首页（输入与选择）
- `/jobs/:jobId` 进度页（实时进度）
- `/jobs/:jobId/result` 结果页（统计 + ZIP 下载）

## 2. 设计原则

- 3 步完成：输入/选择 → 开始下载 → 下载 ZIP。
- 明确状态：输入可用性、任务运行中、失败原因、可下载。
- 运营友好：无需命令行，无需理解技术细节。

## 3. 首页（/）

### 3.1 区块结构

1. 顶部
   - 标题：汽车之家车型物料下载
   - 说明：支持“搜索车系”或“直接输入车系 ID”
2. 卡片：方式 A（搜索车系）
   - 输入框：品牌 + 车型官方名称（placeholder：例如“特斯拉 Model Y”）
   - 按钮：搜索车系
   - 结果列表：
     - 每行展示：车系名称 + 车系 ID + 辅助信息（厂商/级别）
     - 行点击选择；被选中状态高亮
3. 分隔文字：或
4. 卡片：方式 B（直接输入车系 ID）
   - 输入框：车系 ID（数字）
5. 主按钮：开始下载
   - disabled 条件：没有有效 seriesId

### 3.2 交互细节

- 搜索中：列表区域显示加载状态。
- 搜索失败：展示错误提示，同时提示可改用车系 ID。
- 开始下载：创建任务成功后自动跳转进度页。

## 4. 进度页（/jobs/:jobId）

### 4.1 区块结构

1. 顶部信息
   - 车系：名称（若有）+ ID
   - 状态标签：排队/下载中/已完成/失败
2. 进度条
   - 百分比：`done/total`（若 total 未知则展示“已完成 X”）
3. 当前阶段
   - 文案：例如“正在下载：01_外观图”
4. 统计
   - 成功数/失败数
5. 错误摘要（可折叠）
6. 完成后
   - 自动跳转结果页，或展示“查看结果”按钮

## 5. 结果页（/jobs/:jobId/result）

### 5.1 区块结构

1. 完成概览
   - 总耗时
   - 成功/失败数量
2. 下载区
   - 按钮：下载 ZIP
   - 文案：目录结构说明（展示 6 个根目录）
3. 失败说明（如有）
   - 展示失败原因摘要
   - 按钮：重新下载（新建任务，跳转进度页）
